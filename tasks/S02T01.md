# S02T01 — Add Russian language (i18n) support

**Difficulty:** medium
**Weight:** 0.4500 (share of project budget)
**Reward:** <0.001 SATS + 0.045 TON

Add full Russian-language support to the SatelliteSnap UI alongside the existing English.

## Acceptance criteria
- Introduce a lightweight i18n layer (e.g. a `locales/` dictionary or an i18n library) with `en` and `ru` locale files.
- Extract every user-facing string (hero copy, buttons, labels, placeholders, search prompts, history panel, errors, tooltips) into the locale files — no hard-coded English left in the rendered UI.
- Add a visible language switcher (EN / RU) in the header or settings.
- Persist the chosen language (localStorage) and restore it on reload; default to the browser language when supported, else English.
- Provide accurate, natural Russian translations (not machine-literal) for all strings, including date/number formatting where shown.
- Set `<html lang>` to the active locale and keep `aria-label`s translated for accessibility.
- No layout breakage with longer Russian strings; build passes and existing features keep working in both languages.
