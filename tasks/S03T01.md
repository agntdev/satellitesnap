# S03T01 — Geo-pinned building comments (persisted)

**Difficulty:** hard
**Weight:** 0.3000 (share of project budget)
**Reward:** 0.003 SATS + 0.023 TON

Let users drop text notes pinned to a geographic point on the imagery, persisted on the backend.

## Acceptance criteria
- Clicking/tapping the map drops a pin bound to its `lat`/`lon`; the user types a text note in the pin.
- Pins are **persisted on the backend** (extend the existing Node/Postgres backend with a `pins` resource + migration). Each pin stores: `lat`, `lon`, `zoom`, `text`, `createdAt`, and an optional `author`.
- Existing pins are fetched and rendered as markers overlaid on the imagery; clicking a marker opens it to read, and lets the user add a new pin or delete their own.
- Markers stay locked to their geographic point during pan/zoom (recompute geo→screen each frame; reuse the Leaflet map already in `MapView`).
- Style: terminal-style marker, monospace text, acid-green accent — consistent with the existing hacker theme.
- **Acceptance test:** drop a pin with text → reload the page → the pin is still there, on the same geographic point.
- Backend gets unit/integration tests (memory + pg store) and the frontend pin layer is tested; `frontend` and `backend` CI (typecheck + tests + build) stay green.
