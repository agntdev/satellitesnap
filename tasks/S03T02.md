# S03T02 — Spectral & radar modes (Sentinel Hub / Copernicus)

**Difficulty:** hard
**Weight:** 0.3000 (share of project budget)
**Reward:** 0.003 SATS + 0.023 TON

Add a segmented control overlaid on the imagery that switches the source layer between spectral/radar modes ("spy satellite").

## Modes
- **TRUE COLOR** — default (current behaviour).
- **NDVI / FALSE-COLOR (NIR)** — vegetation highlighted (Sentinel-2 L2A; NIR B8 + Red B4).
- **THERMAL** — thermal contrast (Landsat 8/9 TIRS band 10 via the same provider). If the provider has no thermal collection available, **flag this in the UI and fall back to the nearest available analogue — do not fabricate data.**
- **SAR** — Sentinel-1 GRD radar (VV/VH); sees through clouds and works at night.

## Implementation
- Use **Sentinel Hub / Copernicus Data Space Ecosystem** (OGC WMS/WMTS + evalscript) as the tile source. Sentinel-2 L2A for TRUE/FALSE-COLOR/NDVI, Sentinel-1 GRD for SAR.
- Switching a mode swaps the layer/evalscript for the **current bbox** — the point and zoom are preserved across switches.
- Show the active-mode label and, when available, the capture date and cloud-cover %.
- Credentials: Sentinel Hub/CDSE needs auth (instance ID / OAuth). Keep secrets out of the static bundle — use a build-time configurable instance/env var (and/or a thin backend proxy); document setup in the README and degrade gracefully when unconfigured.

## Acceptance criteria
- Switch between all 4 modes **without a page reload**, on the same point, each rendering visually correctly for its mode.
- Active-mode label (+ date / cloud % where available) is shown.
- Tests cover the layer/evalscript selection logic; CI stays green.
